Sources et préparation des données

Les fichiers CSV sont diffusés par Football-Data. Le site compile des données provenant de plusieurs fournisseurs, indiqués dans son dictionnaire des données.

Nous avons conservé les matchs de Ligue 1 de cinq saisons complètes, soit 1 678 rencontres. Les données ont été téléchargées le 22 octobre 2026.

méthodes de calcul

  • Anneau : compter les victoires à domicile, les nuls et les victoires à l’extérieur.
  • Courbe : diviser les victoires à domicile par le nombre de matchs de la saison, puis multiplier par 100.
  • Barres : additionner les tirs cadrés des équipes ayant le même résultat, puis diviser par leur nombre d’observations.
  • Heatmap : pour chaque match, calculer deux différences : tirs cadrés domicile moins extérieur et buts domicile moins extérieur ; puis compter les matchs pour chaque couple d’écarts, ce nombre donne la couleur d’une case.

Pour les barres, un match compte pour deux observations, une par équipe. Un match nul ajoute donc deux observations dans la catégorie « Nul ».
